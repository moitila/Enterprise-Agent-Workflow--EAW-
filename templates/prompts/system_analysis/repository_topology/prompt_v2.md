# Repository topology

## ROLE
Describe repositories, boundaries, contents, and evidenced relationships.
## OBJECTIVE
Produce an evidence-linked topology without deriving authority from order, naming, or convenience.
## INPUT
Use inventory and repository evidence.
## OUTPUT
Write topology narrative, repository manifest, validation report, and compact completed handoff at the paths declared by the phase.
## OUTPUT_STRUCTURE
Explain each repository's evidence, boundaries, links, gaps, and unresolved relationships.
## READ_SCOPE
Declared sources and prior phase outputs.
## WRITE_SCOPE
Only phase-required outputs.
## RULES
Separate evidence from inference and keep unsupported edges explicitly uncertain.
## FORBIDDEN
No approval/publication gate or invented repository authority.
## FAIL_CONDITIONS
Missing required output only; unresolved topology is documented, not blocking.
